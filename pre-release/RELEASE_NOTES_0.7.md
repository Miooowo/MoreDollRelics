# MoreDollRelics 0.7 (2026-07-09)

## Added
- 新增遗物「玩偶的邀请函」：击败 3 名精英后，第二幕问号房可触发玩偶室，触发后失效。
- 邀请函现已加入湼奥正向奖励随机池，并可由湼奥骨骰奖励随机获得。
- 新增佛珠手链暗改：第二幕每个未触发玩偶室的问号房会使下一次触发概率 +15%（可叠加）。

## Changed
- 邀请函稀有度改为先古（Ancient），并从「传说是真的 / 沉没雕像」事件来源移除。
- 王筱巫玩偶免死效果增强：回复至 7 点生命、获得 999 格挡，并立即打出四个牌堆中的全部卡牌；该战斗后续每回合开始获得 99 格挡。
- 狗王玩偶与娜娜因猫球数值完成新一轮平衡调整。

## Fixed
- 修复玩偶室在同一幕可能被重复强制触发的问题。
- 修复特定先古事件流程中可能因问号房替换逻辑导致卡住的问题。
